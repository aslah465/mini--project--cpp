📊 Student Mark Analyzer

📌 Project Description

Student Mark Analyzer is a simple C++ project designed to analyze students' marks. It helps calculate the total marks and average marks of students.

🚀 Features

- Enter the number of students.
- Input marks for each student.
- Calculate total marks.
- Calculate average marks.
- Analyze student performance.

🛠️ Technologies Used

- C++
- Visual Studio Code
- Git & GitHub

💻 How to Run

1. Clone this repository.
2. Open the project in VS Code.
3. Compile the C++ program:

g++ studentmarkanalyzer.cpp -o studentmarkanalyzer

4. Run the program:

./studentmarkanalyzer

For Windows PowerShell:

.\studentmarkanalyzer.exe
